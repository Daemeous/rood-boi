# The default lighting pack

The lighting every player gets (settings key `lighting_packs`, default
`default`). Format and workflow: [../README.md](../README.md).

- `generated/zoneZZ_roomRR.txt`: generator output (none yet). Regenerated
  wholesale; do not edit: override in `rooms/` instead.
- `rooms/zoneZZ_roomRR.txt`: hand-authored lighting, by room (none yet).
  The editor's **Promote to pack** writes here.

Rooms are numbered as the game numbers them (zone, room in that zone); the
editor's Room Browser (Ctrl+R) lists them with their names and takes you
to any of them.
